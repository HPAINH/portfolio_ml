NLP · LLM Securityкурсовая НИТУ «МИСИС», 2026

        
PI-Guard: детектор prompt injection для корпоративных LLM

        
Шлюз перед LLM-ассистентом банка: проверяет запрос и блокирует попытки переписать инструкции модели.

        
    
          
  • Данные: двуязычный датасет на 8 965 запросов (64% на русском) из 5 открытых корпусов, разбиение без утечек и отложенная выборка из незнакомых источников.
    • 
          
  • Метод: эмбеддинги multilingual-e5 и признаки семантического отклонения — удалённость от задачи ассистента, близость к типам атак, скачок смысла внутри запроса.
    • 
          
  • Оценка: порог под бизнес-ограничение FPR ≤ 2%, бутстреп-интервалы, абляция, устойчивость к 6 видам обфускации, задержка p50/p95 на CPU.
    • 
          
  • Сервис: FastAPI POST /check, логирование инцидентов, Gradio-демо, Docker.
    •

  • Инженерия: FastAPI, React, Docker Compose, CI в GitHub Actions, защита от prompt injection и SSRF, изоляция данных клиентов.

Document AIpet-проект + хакатон

        
Обработка документов: OCR и vision-LLM там, где они нужны

        
Конвейер PDF → Markdown, который решает для каждой страницы, достаточно ли текстового слоя или нужна мультимодальная модель.

        
    
          
  • Классификация страниц: сканы, таблицы, многоколоночная вёрстка, доминирующие изображения — по метрикам блоков и шрифтов.
    • 
          
  • Два пути: быстрый по текстовому слою (PyMuPDF) и vision-LLM (GigaChat, OpenAI-совместимый API, Anthropic) с промптом против галлюцинаций.
    • 
          
  • Скорость и стоимость: параллельные вызовы модели, сшивка абзацев между страницами, модель вызывается только для сложных страниц.
    • 
          
  • Сервис: FastAPI с загрузкой файлов, Docker, 8 unit-тестов. На хакатоне — Tesseract OCR с учётом колонок для сканов.

02 · интерактив
Подберите порог сами

      
Главное инженерное решение в PI-Guard — не модель, а порог. Низкий блокирует обычных клиентов, высокий пропускает атаки. Попробуйте уложиться в требование бизнеса: не больше 2 ложных блокировок на 100 клиентов.

    

    

      
оценки модели на валидации700 обычных запросов · 300 атак
